# 一面 · 数字名片

面向个人商务场景的数字名片微信小程序，附 H5 预览。前端基于 [unibest 4.4.1 官方模板](https://github.com/feige996/unibest)，使用 Uni-app、Vue 3、TypeScript、Pinia、UnoCSS 和 z-paging；后端使用微信云开发（云函数、云数据库、云存储）；H5 通过 Fastify 网关访问相同云端数据。

## 第一版功能

- 免费与 VIP：免费账号可编辑基础资料、头像和联系方式，使用固定简约名片及分享，名片夹最多收藏 10 张；VIP 名片夹容量为 50 张，并解锁所有模板、图文视频、多页面编排、私密留言与数据统计。管理员开通，支持长期或指定到期时间，暂未接入支付。账号页显示权益与账号编号；到期保留高级内容，重新开通后恢复，已有收藏仍可查看和取消。操作见 [会员管理](docs/CloudDevelopment.md#vip-会员管理)。
- 我的名片：姓名、头像、职位、公司、城市、简介、专业标签和联系方式。
- 分步编辑：按「身份与联系 → 业务与展示 → 风格与发布」填写；身份、城市、标签和联系方式直接可见。商务名片、业务展示、个人主页分别提供服务、公司、案例、作品等常用内容入口，可混合添加。支持连续填写，页面与排版、模块更多设置和样式细节按需展开；切换步骤和预览保留输入，保存错误会定位并展开对应设置。
- 一键主题：12 套完整模板，按简约、商务、雅致、创意筛选，附适用场景。新增黑金尊享、青瓷留白、杂志艺文、落日暖橙、极光科技、自然森语；封面、资料卡、内容模块与留言板使用统一风格。
- 编辑与实时预览：经典、居中、简约三种布局，三种预设主题及自由配色；自定义封面标题、文案、底部署名、头像形状与装饰；选择职位、公司、城市和标签的显隐，支持恢复默认风格及公开/私密设置。
- 个人主页编排：最多 8 个模块，自定义标题及服务、作品、合作需求等文字内容；添加、删除、隐藏模块，桌面 H5 拖拽排序，手机与小程序支持上移/下移，完整预览与访客展示同步。
- 分页与分栏：最多 6 个命名页面，可调整顺序、为模块选择所属页面；每页独立选择单栏或双栏，模块可占一栏或通栏，手机同样支持双栏。访客可点页面名称或上一页/下一页切换；删除页面会把模块移到相邻页面，旧名片默认单页单栏。
- 人物主页：竖版大图封面、叠加姓名和身份、圆形图标导航，点击后进入独立内容视图；默认提供个人简介、公司简介、产品服务、联系我们四个入口，名称和图标可修改。每页可选卡片模块或无边框的连续图文，公司介绍可组合纵向图片、正文和视频。封面支持上传（最大 8 MB）或 HTTP(S) 图片链接，并沿用媒体的归属和公开/私密规则。
- 媒体模块：图片上传与多图网格/纵向展示，每个模块最多 6 张；视频上传、封面与播放；链接模块自定义按钮文字。图片最大 8 MB，视频最大 50 MB，也支持 HTTP(S) 图片/视频直链。上传进度、格式和大小错误会在编辑页展示。
- 分享：微信好友分享、小程序码；H5 生成真实链接二维码，支持下载和复制链接。
- 名片夹：所有账号可收藏、取消收藏、分页及按姓名、公司、标签搜索；普通用户最多收藏 10 张，VIP 最多 50 张，达到上限后需先取消收藏再新增；微信扫码打开名片。
- 联系人：拨打电话、复制微信号及邮箱、保存手机通讯录；H5 下载 vCard。
- 数据概览：浏览、被收藏、收藏人数和近七天趋势。统计真实接口数据；自己访问不计数，同一访客同一北京时间日期只记一次。
- 账号：仅提供微信直接注册、微信直接登录和退出登录；通过微信云函数可信上下文识别账号，保留可撤销的云端会话及账号间的数据隔离。

本地和正式环境均使用真实微信账号，首次微信授权后创建空白私密名片，再次使用同一微信进入原账号。微信登录、微信小程序码和真机操作需要自己的微信配置。H5 保留公开名片预览，注册与登录请在微信小程序中完成。体验模式及其入口已关闭，旧体验登录凭证不再恢复登录，既有数据库资料保留。自动化测试使用显式启用的隔离示例账号，不影响运行中的项目。

点击顶部「我的账号」图标或「设置 → 账号管理」进入账号页面，选择「微信直接注册」或「微信直接登录」。两者均通过可信微信身份创建或恢复同一账号，名片、分享链接、收藏、留言和统计继续保留；退出后不会自动恢复登录。用户名密码注册、登录、绑定及修改密码入口和接口均已停用，历史账号资料不删除。

## 云开发启动与部署

新账号和没有会员记录的历史账号默认免费。VIP 权限由云端逐次校验，前端不能自行开通；部署会员功能时，先更新 `digitalCard` 云函数，再发布小程序/H5。

已配置小程序 AppID `wx0ea087f9c508f86f`、云开发环境 `cloud1-d5g9aguo13adf0f36`，云函数为 `digitalCard`。小程序直接使用 wx.cloud；账号、名片、收藏、留言与统计保存在云数据库，媒体保存在云存储。

按 [云开发部署说明](docs/CloudDevelopment.md) 创建集合、设置权限并上传云函数，然后运行：

```powershell
npm run cloud:prepare
npm run dev:mp
```

微信开发者工具导入 DigitalCard 根目录。H5 需要在 backend/.env 配置腾讯云服务端凭证，再运行 `npm run dev:api` 和 `npm run dev:web`。没有云凭证时网关返回明确的配置提示；不会将注册数据存回 SQLite。H5 正式包默认使用同域 `/api`，部署时需将 `/api/` 反向代理到网关；独立 HTTPS 网关可在 `frontend/env/.env.production.local` 中覆盖 `VITE_SERVER_BASEURL`。正式 H5 构建会拒绝本机网关地址，详见部署说明。

原 SQLite 和本地媒体未删除。迁移已有正式账号可先执行 `npm run cloud:migrate` 只读预检，具体导入与备份步骤见上述文档。

## 校验

```powershell
npm run test:api
npm run test:cloud
pnpm --dir frontend type-check
pnpm --dir frontend lint
pnpm --dir frontend test:run
npm run build:web
npm run build:mp
npm run test:e2e
npm run test:e2e:cloud
```

端到端测试使用 Playwright 与本机 Microsoft Edge，在 3100/9100 端口自动启动独立测试 API 和 H5，使用临时数据库及媒体目录；测试 API 仅提高全局请求额度，生产限流不变。如果没有 Edge，可在 `playwright.config.ts` 中移除 `channel` 并运行 `npx playwright install chromium`。覆盖仅微信账号入口、H5 小程序操作提示、退出后不自动登录，以及编辑、保存后刷新、二维码、名片搜索、取消收藏、公开访客和移动/桌面布局。云网关浏览器测试同时确认旧密码接口被拒绝；真实微信身份的创建与恢复由云端测试覆盖，真机授权仍需微信环境验证。截图保存在忽略提交的 `artifacts/`。
